## 서버 켜기 (맥에서)

```bash
cd /Users/nohhyeseong/PROJECTS/new_app_plan/prototype && /usr/bin/python3 -m http.server 3012 --bind 0.0.0.0
```

★ **반드시 `/usr/bin/python3`** 를 씁니다. Homebrew python 은 macOS 방화벽에
등록돼 있지 않아 **폰에서 연결이 안 됩니다** (맥에서는 되는데 폰에서만 안 되어
원인을 찾는 데 시간이 걸린다). 방화벽에 허용된 것은 시스템 python 쪽입니다.

## 회의에서 볼 것 — 5탭

| 탭 | 보여줄 것 |
|---|---|
| **지도** | 전국 줌에서 **시·군·구 집계**(색+숫자) → 지역을 누르면 들어감 → 장소 핀. 사람 수 필터(2·5·20명) |
| **갈 곳** | 묶음 5개. 표지가 **반응으로 정해진다**(기관 사진도 진다). 거리는 `차로 N분` |
| **소식** | 시간순. 포스트마다 **왜 내게 보이는지** 한 줄. 좋아요·저장만(댓글 없음) |
| **스페이스** | **함께 채운 지도** — 합집합 / 같이 간 곳 vs 혼자 간 곳 / 누가 어디를 열었나 |
| **마이** | 정복률·공유 카드·A컷 금고(대표 픽)·서버에 있는 내 기록 |

## 실제로 눌러 볼 것

1. `+` → **앨범에서** → 여행 하나 → 정거장마다 장소 고르기 → 한 줄 메모 → 등록
   → 완료 화면에 **서버로 올라간 결과**가 뜹니다
2. 마이 → **시작하기(가입 없이)** → 사진 한 장 올려보기 (기기에서 줄여서 올라감)
3. 장소 사진 탭 → 뷰어 → **스페이스 기록에만 댓글**이 붙는 것
