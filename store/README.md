내용은 전부 **진짜**다: 한국관광공사 실제 행사·사진, 실제 날짜, 실제 소요시간.

## 왜 한 장뿐인가 (§13.150)

나머지 네 장(`지도에 쌓인 기록` · `앨범 훑기` · `장소 상세` · `함께 채운 지도`)은
**기록이 있어야** 그럴듯하다. 그러려면 시뮬레이터 앨범에 사진을 넣어야 하는데,
**`xcrun simctl addmedia` 가 Xcode 26.6 에서 깨져 있다**:

```
NSInvalidArgumentException: Invalid domain=nil
  at -[SimDevice addMedia:error:]
```

기기 두 대 · CoreSimulator 서비스 재시작 · 창에 끌어다 놓기 · Safari 길게 눌러
저장 — **네 가지 다 실패했다.** 우리 코드와 무관한 애플 도구 버그다.

## 그래서 언제 찍나

**TestFlight 로 직접 몇 장 올려 본 뒤.** 그러면 진짜 기록이 생기고, 그걸로 찍는
것이 어차피 제일 좋다 — `STORE.md` 가 원래 그렇게 적어 두었다:

> *"2·3·5번은 기록이 있어야 그럴듯하다 — 테스터가 쓰기 시작한 뒤에 찍는 것이 낫다."*

★ **애플은 스크린샷 한 장만 있어도 제출을 받는다.** 이것이 출시를 막지 않는다.

★★ 찍을 때 **사진에 맞는 장소**를 고를 것. 한번은 제주 절벽 사진에 경복궁을
   붙이려다 말았다 — 스토어 스크린샷에서 바로 이상해 보인다.
